# Создать программу  которая по имени города будет выдать страну и язык.
 
## Этапы выполнения:
- Считать файл с городами. и зарнузить в словарь
- спросить у пользователя город.
- найти город в словаре и вывести страну и язык.
- если города нет, вывести сообщение что города нет.
- если город не один, вывести все страны и языки.
- если пользователь ввел пустую строку, спросить снова.
- если пользователь ввел "exit" или "q"", завершить программу.
